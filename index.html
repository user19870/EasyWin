開始使用 EasyWinGui

歡迎學習 EasyWinGui —— 一個純 C++ 實作、輕量高效的 GUI 函式庫。

支援平台： Windows
最低需求： C++11 編譯器
github repo

安裝方式

將 include/easywingui.h 加入編譯路徑。

建立第一個視窗

使用 Window 類別快速建立主視窗。

#include <easywingui.h>
using namespace easywingui;easyw app;
int main() {
app.creatw(L"title",1920,1200);
app.loopAndStopProcessing(); // or while(1){app.runMessage(nullptr);Sleep(1);}
}
